Implement CI/CD pipeline for LorePin CMS UI

This commit implements a comprehensive CI/CD pipeline for the LorePin CMS UI using GitHub Actions. The pipeline automates the testing, building, and deployment processes, ensuring consistent and reliable deployments across different environments.

Key components:
- GitHub Actions workflow for building, testing, and deploying
- ESLint configuration for code quality and consistency
- Firebase configuration for multiple environments
- Deployment scripts for different environments
- Version management with semantic versioning
- GitHub secrets setup script
- Comprehensive documentation

The CI/CD pipeline deploys to three environments:
- Development: When changes are pushed to the develop branch
- Staging: When changes are pushed to the main branch
- Production: After successful deployment to staging

This implementation follows best practices for CI/CD, including automated testing, environment progression, and secure management of sensitive information.
